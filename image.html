Phân loại ảnh với mô hình pretrained

Dùng mô hình pretrained làm feature extractor, đối chiếu với fine-tuning nhẹ trên cùng tập test.

§ 02

Bài toán & tập dữ liệu

Các trường cần điền khi có dữ liệu.

Tên tập dữ liệuChưa cập nhật — nguồn · giấy phép
Bài toánChưa cập nhật — phân loại ≥ 3 lớp
Số ảnhChưa cập nhật — ≥ 5.000 · số ảnh mỗi lớp
Độ phân giảiChưa cập nhật — cạnh ngắn ≥ 128 px · cách resize hoặc padding
Mô hình pretrainedChưa cập nhật — ResNet50 / MobileNetV3 / ViT-B/16
AugmentationChưa cập nhật — flip · random crop · color jitter · normalize
Chia dữ liệuChưa cập nhật — tỉ lệ train / val / test · tránh rò rỉ
§ 03

Điểm cần làm rõ trong bài

  • Không dùng MNIST, Fashion-MNIST hay CIFAR-10 làm tập chính — các tập này chỉ để minh hoạ pipeline.
  • Nêu rõ dùng feature extractor (đóng băng backbone) hay fine-tuning nhẹ vài tầng cuối.
  • Hình đạt điểm sáng tạo: các mẫu bị dự đoán sai; so sánh mô hình cổ điển trên vector pretrained với transfer learning.
