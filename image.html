Bài Image (tự chọn)

Phân loại ảnh với mô hình pretrained

Bài này dùng mô hình pretrained để trích đặc trưng ảnh, rồi so với cách fine-tune nhẹ trên cùng một tập test.

Bài này đang làm, kết quả sẽ được cập nhật khi notebook xong.

Sản phẩm nộp

Notebook cần chạy được Run all từ tài khoản khác.

  • NotebookChưa cập nhậtGoogle Colab + bản trên GitHub.
  • Báo cáo PDFChưa cập nhậtTóm tắt cách làm, bảng metric và kết luận.
  • Video trình bàyChưa cập nhật5–10 phút, YouTube Public hoặc Unlisted.

Bài toán & tập dữ liệu

Các thông tin này sẽ điền khi có dữ liệu.

Tên tập dữ liệunguồn, giấy phép (chưa cập nhật)
Bài toánphân loại ≥ 3 lớp (chưa cập nhật)
Số ảnh≥ 5000, kèm số ảnh mỗi lớp (chưa cập nhật)
Độ phân giảicạnh ngắn ≥ 128 px, cách resize hoặc padding (chưa cập nhật)
Mô hình pretrainedResNet50 / MobileNetV3 / ViT-B/16 (chưa cập nhật)
Augmentationflip, random crop, color jitter, normalize (chưa cập nhật)
Chia dữ liệutỉ lệ train / val / test, tránh rò rỉ dữ liệu (chưa cập nhật)

Điểm cần làm rõ trong bài

  • Không dùng MNIST, Fashion-MNIST hay CIFAR-10 làm tập chính. Các tập này chỉ dùng để minh hoạ pipeline.
  • Nêu rõ dùng feature extractor (đóng băng backbone) hay fine-tuning nhẹ vài tầng cuối.
  • Hình đạt điểm sáng tạo: các mẫu bị dự đoán sai; so sánh mô hình cổ điển trên vector pretrained với transfer learning.
