Phân loại văn bản tiếng Việt

Phân loại văn bản tiếng Việt trên tập dữ liệu nhóm tự thu thập, so sánh TF-IDF với biểu diễn embedding.

Đang thực hiện — kết quả sẽ cập nhật khi notebook hoàn thành

§ 01

Sản phẩm nộp

Notebook phải chạy được Run all từ tài khoản khác.

  • NotebookChưa cập nhậtGoogle Colab + bản trên GitHub.
  • Báo cáo PDFChưa cập nhậtTóm tắt cách làm, bảng metric và kết luận.
  • Video trình bàyChưa cập nhật5–10 phút, YouTube Public hoặc Unlisted.
§ 02

Bài toán & tập dữ liệu

Các trường cần điền khi có dữ liệu.

Tên tập dữ liệuChưa cập nhật — nguồn · cách thu thập
Bài toánChưa cập nhật — phân loại chủ đề / cảm xúc / …
Số mẫuChưa cập nhật — ≥ 2.000
Ngôn ngữChưa cập nhật — Tiếng Việt
Số lớpChưa cập nhật — số lớp · phân bố mẫu mỗi lớp
Tiền xử lýChưa cập nhật — chuẩn hoá unicode · tách từ · loại stopword
Chia dữ liệuChưa cập nhật — tỉ lệ train / val / test
§ 03

Điểm cần làm rõ trong bài

  • Mô tả rõ quy trình crawling: nguồn, khoảng thời gian, số trang, cách loại bỏ trùng lặp.
  • So sánh TF-IDF với embedding trên cùng tập test.
  • Hình đạt điểm sáng tạo: từ hoặc n-gram phân biệt các lớp; confusion matrix kèm ví dụ bị gán sai.
